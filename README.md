# To-Do List App 

A simple and intuitive to-do list application built using HTML, CSS, and JavaScript. This app allows users to easily add, delete, and mark tasks as completed, helping them stay organized and productive.

## Features 
- Add new tasks to your to-do list.
- Mark tasks as completed.
- Delete tasks from the list.
- Persistent storage using local storage, so your tasks are saved even after refreshing the page.

## Technologies Used 
- Frontend: HTML, CSS
- Backend: Javascript, local storage

## How to Use ⚙
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Add tasks to the list and manage them as needed.
